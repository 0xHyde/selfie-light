# 自拍补光灯 (Selfie Light)

把手机屏幕变成自拍补光灯的 Web MVP。全屏补光 + 前置相机预览拍照，纯静态页面，零构建。

## 功能

- 4 个自拍预设：暖白 / 冷白 / 粉调 / 自然光
- 色温滑杆（3000–6500K，黑体色温近似）+ 亮度滑杆（感知亮度）
- 轻点屏幕沉浸模式：隐藏全部 UI，只剩纯色光
- 前置相机镜像预览 + 点击即拍（canvas 自拍镜像）
- 照片条：Android 点保存下载 / iOS 长按存相册
- 屏幕防休眠（Screen Wake Lock）

## 本地运行

```bash
python -m http.server 8000
# 打开 http://localhost:8000 （localhost 即安全上下文，相机可用）
```

## 真机测试

推送到 GitHub 后开启 Pages，手机扫码访问 HTTPS 页面即可。

## 已知边界

- Web 无法控制系统亮度（两端皆如此）→ 用黑色遮罩模拟"感知亮度"；使用前需手动把系统亮度拉满（iOS：控制中心 / 安卓：快捷面板）
- iOS Safari 不支持元素全屏
- Web 无法直接写入系统相册 → iOS 长按保存
